Evidence standard

Completed is not the same as verified.

The ledger records what can actually be established. A Git commit can timestamp an artifact; it cannot prove that no AI was used. A benchmark can reproduce a result; it cannot prove that an employer's interview process will recognize it.

Where possible, the evidence chain is: task → submission → rubric → verifier → receipt → live defense.

Completed

The required artifact exists.

Replayed

A clean run reproduced the committed result.

Portfolio-ready

The benchmark met its score threshold with no critical failure.

Externally verified

An identified third party independently evaluated or proctored the work.

Training loop

Train backward from the market.

New benchmark projects are selected from recurring task primitives in current remote job descriptions. The objective is maximum employability signal per hour of attention and AI/Codex usage—not collecting projects for their own sake.

  1. 1. Observe

    Find current remote roles and extract the work that appears repeatedly.

  2. 2. Build

    Create one bounded project that exercises several valuable primitives at once.

  3. 3. Verify

    Score, replay, disclose AI use, inspect failure cases, and defend the result live.

  4. 4. Publish

    Add only the strongest evidence to this page and the machine-readable ledger.

Evaluation challenge

Pick a relevant artifact and try to break it.

If the role requires something not represented here, the most useful next step is a representative task with a clear rubric. I prefer demonstrating the work to arguing from prestige signals.
